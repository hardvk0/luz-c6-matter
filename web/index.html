Luz C6

Relé como luz Matter sobre Thread para ESP32-C6, con MQTT opcional. Versión ….

Instalar desde el navegador

Conecta la placa por USB (Chrome o Edge de escritorio) y pulsa el botón. Si ya está en uso, el instalador te ofrece borrar o conservar los datos.

Este navegador no admite Web Serial. Usa Chrome o Edge en un ordenador. Esta página necesita HTTPS para acceder al puerto USB.

Después de instalar

  1. Conéctate al Wi-Fi Luz-C6-xxxxxx (contraseña inicial luzconfig); se abre solo el portal de configuración.
  2. Rellena MQTT si lo quieres y pulsa Guardar y reiniciar.
  3. En tu app de Matter, añade un dispositivo con el código que muestra el portal (emparejamiento por Bluetooth).

Actualizaciones OTA

  • Matter: sirve luz_c6-ota.bin desde un proveedor OTA de Matter.
  • MQTT o portal: usa luz_c6.bin (publícalo en <base>/ota/set como URL, o súbelo desde el portal).
